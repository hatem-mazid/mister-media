# Mister Media website — how to add a project

This short guide is for the Mister Media team. It explains how work should be prepared so it looks correct on **mister-media.com**, not only on Behance.

The website and Behance are two different places:

| | Behance | Website |
| --- | --- | --- |
| Purpose | Full studio archive | Selected work that represents the agency today |
| Categories | Behance’s own tags | The **8 Mister Media services** (see below) |
| Visibility | Public or private on Behance | Show, feature, or hide — independently |

You can keep a project public on Behance and still hide it on the website. You can also show a project on the website with a different category than Behance.

---

## 1. Where a project appears

Once a project is **published** on the website, it can show in three places:

1. **Projects page** (`/projects`) — the full wall, filterable by service  
2. **Project page** — name, service, short text, then the gallery  
3. **Home + footer** — only if it is marked **Featured** (keep this list small, about 8–12 pieces)

If it is **hidden**, it does not appear anywhere on the site.

---

## 2. How to add a new project (the right way)

Do this **on Behance first**, then tell us it is ready.

### Step A — Create or update the Behance project

1. Use the **final project name** you want on the website (brand names stay as published, including Arabic).
2. Write a **short description** (2–6 sentences). This text is shown on the website. Do not add “Thank you for watching” or social-media outros.
3. Set a **cover image** (the thumbnail). This is the image used on the home wall and the projects wall.
4. Add the **gallery** as **separate files**, one image (or video) per frame — not one tall collage.
5. Publish the project on the Behance profile: [behance.net/Fouad-Mazid](https://www.behance.net/Fouad-Mazid)

### Step B — Send us a short brief

Copy the form at the end of this document and fill it in (WhatsApp, email, or this file). We then connect it to the correct service, visibility, and layout on the website.

We will not invent categories, claims, or translations. If a field is empty, we leave it empty.

---

## 3. Cover image (the main picture)

The cover is the **one picture** people see in the grid. Choose it as carefully as a poster.

**Do**

- Export a dedicated cover (packshot, logo on a clean background, or the strongest key visual).
- Use a **landscape** image, roughly **4:3** (for example 1600 × 1250 or 1920 × 1440).
- Keep important content away from the edges (the tile is slightly cropped on hover).
- Make sure the brand is readable at small size.

**Don’t**

- Use a random photo from the middle of the gallery.
- Use a very tall / very wide image as the cover.
- Put many logos or many products into one cover.

If the cover is weak, the whole projects page looks weak — even when the inner gallery is excellent.

---

## 4. Gallery images (the project page)

The project page shows **each file you upload**, in order.

### The rule that matters most

**One idea = one file.**

| Correct | Incorrect |
| --- | --- |
| Logo on light background | One long JPEG with 6 logos stacked |
| Logo on dark background | A Photoshop contact sheet exported as a single image |
| Business card mockup | A 600 × 1200 “poster” of the whole presentation |
| Packaging front, then packaging back | |

**Example:** *Baby Castle (kids wear)* currently has **one tall image** on Behance. On the website that becomes one very long picture. For a logo project we need the frames **split**, for example:

1. Logo (colour)  
2. Logo (black / white)  
3. Logo on mockup  
4. Stationery / application  

The same applies to **Logo Collection 2016**, **Logo Collection 2010**, and **Suter international**.

### Recommended specs

- JPG or PNG  
- Longest side **1600–2500 px** (larger is fine; we optimise for the web)  
- Same style and colour background across the set, when possible  
- Order them on Behance top-to-bottom in the order they should appear on the site  

### Video

- Upload to **YouTube** or **Vimeo** and embed that on Behance (or send us the link).  
- Do not send only a Behance-hosted file we cannot embed cleanly.

## 6. Show, hide, or feature

For every project, choose one visibility:

| Status | Home | Projects wall | Project page |
| --- | --- | --- | --- |
| **Published** | No | Yes | Yes |
| **Featured** | Yes | Yes | Yes |
| **Hidden** | No | No | No |

Notes:

- **Featured** should be the best current work only (about 8–12). Older or weaker pieces can stay **Published** so the archive is still complete.
- **Hidden** is the right choice for: event recaps, thank-you posts, duplicate galleries, student/old work you no longer want to represent, or anything unfinished.
- Changing Behance to private is **not** required in order to hide a project on the website.

Projects we suggest you review for **Hidden** (you decide):

- Behance Syria – Gaziantep 15 May 2016 (event recap)  
- Duplicate HAMSA galleries (keep one)  
- Very old logo collections, if they no longer represent the studio

## 7. Names, language, and text

- Keep **brand names** as they are on Behance (Sona, Dominar, حوراء, HAMSA, …). Do not invent an English or Arabic translation of a brand.
- Description: short, factual, in the language you want on the site. If you want both English and Arabic descriptions, send **both**.
- We will not write client praise, awards, or results unless you provide them.

# إضافة المشاريع إلى الموقع — دليل Mister Media

هذا الدليل لفريق Mister Media. يوضّح كيف تُجهَّز الأعمال لتظهر بشكل صحيح على **موقع الشركة**، وليس على Behance فقط.

الموقع وBehance مكانان مختلفان:

| | Behance | الموقع |
| --- | --- | --- |
| الغرض | أرشيف الاستوديو الكامل | أعمال مختارة تمثّل الوكالة اليوم |
| التصنيف | وسوم Behance | **خدمات Mister Media الثمانية** |
| الظهور | عام أو خاص على Behance | إظهار، تمييز، أو إخفاء — بشكل مستقل |

يمكن إبقاء المشروع عامًا على Behance وإخفاؤه من الموقع. ويمكن عرض المشروع على الموقع بتصنيف مختلف عن Behance.

---

## 1. أين يظهر المشروع؟

إذا كان المشروع **منشورًا** على الموقع، يمكن أن يظهر في ثلاثة أماكن:

1. **صفحة المشاريع** — الجدار الكامل مع التصفية حسب الخدمة  
2. **صفحة المشروع** — الاسم، الخدمة، نبذة، ثم المعرض  
3. **الرئيسية وتذييل الموقع** — فقط إذا كان **مميزًا** (يُفضَّل 8–12 أعمال)

إذا كان **مخفيًا**، لا يظهر في أي مكان على الموقع.

---

## 2. طريقة إضافة مشروع جديد

اعمل **أولًا على Behance**، ثم أخبرنا أن المشروع جاهز.

### أ — على Behance

1. استخدم **الاسم النهائي** كما تريد ظهوره في الموقع (أسماء العلامات تبقى كما نُشرت، بما فيها العربي).
2. اكتب **وصفًا قصيرًا** (2–6 جمل). هذا النص يظهر في الموقع. بدون عبارات شكر أو روابط سوشيال في آخر المعرض.
3. ضع **صورة الغلاف** (المصغّر). هذه هي صورة الجدار في الرئيسية وصفحة المشاريع.
4. أضف المعرض **ملفًا ملفًا** — صورة (أو فيديو) لكل إطار، وليس كولاجًا طويلًا واحدًا.
5. انشر المشروع على الحساب: [behance.net/Fouad-Mazid](https://www.behance.net/Fouad-Mazid)

### ب — أرسل لنا ملخصًا

انسخ النموذج في نهاية الدليل وعبّئه (واتساب أو إيميل أو هذا الملف). بعد ذلك نربطه بالخدمة الصحيحة وحالة الظهور على الموقع.

لن نخترع تصنيفًا أو ادعاءات أو ترجمات. إذا كان الحقل فارغًا نتركه فارغًا.

---

## 3. صورة الغلاف

الغلاف هو **الصورة الواحدة** التي يراها الزائر في الشبكة. اخترها بعناية الملصق.

**يُفضَّل**

- تصدير غلاف مخصص (منتج، شعار على خلفية نظيفة، أو أقوى إطار).
- صورة **أفقية** بنسبة تقارب **4:3** (مثلًا 1600 × 1250 أو 1920 × 1440).
- إبعاد العناصر المهمة عن الحواف.
- وضوح العلامة حتى بالحجم الصغير.

**يُتجنَّب**

- صورة عشوائية من وسط المعرض.
- غلاف طويل جدًا أو عريض جدًا.
- جمع شعارات أو منتجات كثيرة في غلاف واحد.

---

## 4. صور المعرض (صفحة المشروع)

صفحة المشروع تعرض **كل ملف ترفعه**، بالترتيب.

### القاعدة الأهم

**فكرة واحدة = ملف واحد.**

| صحيح | غير صحيح |
| --- | --- |
| الشعار على خلفية فاتحة | ملف JPEG طويل فيه 6 شعارات فوق بعض |
| الشعار على خلفية داكنة | ورقة اتصال من فوتوشوب كصورة واحدة |
| الموك أب | صورة 600 × 1200 لكل العرض دفعة واحدة |

**مثال:** مشروع *Baby Castle (kids wear)* على Behance صورة واحدة طويلة. على الموقع تظهر كصورة ممدودة. لمشاريع الشعار نحتاج الإطارات **منفصلة**، مثلًا: شعار ملوّن، شعار أبيض/أسود، موك أب، تطبيقات.

ينطبق الأمر نفسه على **Logo Collection 2016** و**Logo Collection 2010** و**Suter international**.

### المواصفات المقترحة

- JPG أو PNG  
- أطول ضلع **1600–2500 px**  
- رتب الملفات في Behance من الأعلى إلى الأسفل بنفس ترتيب الموقع  

### الفيديو

- ارفع على **YouTube** أو **Vimeo** وأرسل الرابط (أو ضعه في Behance).

---

## 5. اختيار التصنيف الصحيح

اختر **خدمة واحدة فقط** من خدمات Mister Media. هذا ما يستخدمه فلتر الموقع. وسوم Behance لا تُعتمد.

انظر جدول الخدمات في القسم الإنجليزي (القسم 5) — الأسماء العربية موجودة في العمود الثاني.

إذا جمع المشروع خدمتين (شعار + تغليف مثلًا)، اختر **القصة الأساسية** للمعرض.

---

## 6. إظهار، إخفاء، أو تمييز

| الحالة | الرئيسية | جدار المشاريع | صفحة المشروع |
| --- | --- | --- | --- |
| **منشور** | لا | نعم | نعم |
| **مميز** | نعم | نعم | نعم |
| **مخفي** | لا | لا | لا |

- **المميز:** أفضل الأعمال الحالية فقط (حوالي 8–12).  
- **المخفي:** تغطيات فعاليات، منشورات شكر، معارض مكررة، أعمال قديمة لا تمثّل الاستوديو، أو عمل غير مكتمل.  
- لا يلزم جعل المشروع خاصًا على Behance لإخفائه من الموقع.

يُفضَّل مراجعة إخفاء: فعالية Behance سوريا، معرض HAMSA المكرر، ومجموعات الشعارات القديمة إن لم تعد تمثّلكم.

---

## 7. الأسماء والنصوص

- أسماء العلامات تبقى كما في Behance. لا نترجم اسم العلامة من عندنا.  
- الوصف قصير وواقعي. إذا رغبتم بنسختين إنجليزي/عربي أرسلوا **الاثنتين**.  
- لا نكتب مديح عملاء أو جوائز أو نتائج ما لم ترسلوها.

---

## 8. جدول المشاريع الحالية

عبّئوا الجدول في القسم الإنجليزي (القسم 8): الإبقاء أو الإخفاء، التمييز، رقم الخدمة من 1 إلى 8، وملاحظات الصور.
